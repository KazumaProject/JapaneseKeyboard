## 修正

- 方向変更のたびにネイティブ popup の位置・大きさを変える処理をやめ、固定したウィンドウ内で表示を切り替えます。
- クパチーノの通常フリックでも、元のキーの文字を表示します。
- 長押しガイドと通常 popup を同時に残さず、指を離した時・キャンセル時に消去します。
- 最下段などで popup がシステムバーへ重ならないよう、描画位置だけを調整します。十字ガイドは全体で配置し、選択変更中に動かしません。
- 候補タブの文字色・選択色を、テーマ変更後の最初の入力画面から更新します。

[修正前の連続フレーム](evidence/before-window-motion.png)では popup が斜めに移動しています。
[修正後の連続フレーム](evidence/after-window-motion.png)では、元のキーの文字を残し、方向の表示が一度に切り替わっています。
