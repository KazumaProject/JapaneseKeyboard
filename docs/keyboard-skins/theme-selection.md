# サムネイル付きテーマ選択

従来の「設定 → テーマ」、新設定画面の「テーマ」のどちらからも、
先頭の「テーマを選択」を開けます。専用の `KeyboardSkinSelectionFragment` に
デフォルト／クパチーノ ライト／クパチーノ ダークをサムネイル付きで表示します。
カードをタップすると選択を保存し、枠と「選択中」で現在のテーマを示します。
戻ると元のテーマ設定に選択名を表示します。

選択で変更する設定は `keyboard_skin_preference` だけです。
デフォルトの色・背景など、既存テーマの設定は保存したままです。
キーボードの高さや入力処理を変更するコードは含めていません。

## テーマの追加

1. `KeyboardSkinId` と `KeyboardSkinRegistry` にテーマを登録します。
2. `KeyboardThemeCatalog` に ID、表示名、説明のリソースを追加します。
3. 日本語・英語のリソースを追加します。

一覧のカード・選択処理はカタログから生成するため、テーマごとの画面分岐は不要です。
`KeyboardThemeCatalogTest` は、保存可能な ID が一覧から欠落していないことと、
デフォルト以外の描画実装が登録されていることを検査します。

サムネイルのクパチーノ背景・キーには本番の描画部品と配色を使用します。
デフォルトは保存済みカスタム配色、またはアプリのテーマ色を使います。
背景画像やキー配置を完全再現する画面ではないため、画面にも配色とキー形状の
イメージであることを明記しています。サムネイルには入力機能を持たせていません。

## 実機検証

`KeyboardThemeSelectionDeviceTest` は Pixel 6 の従来テーマタブから一覧を開き、
各テーマのカードを操作した後、本番 IME で文字を入力します。
選択だけでは他の設定が変化しないこと、画面再生成後の保存、戻り先の表示、
新設定側のテーマ画面からデフォルトへ戻せることも検査します。

最終 APK で上記の実機テストは成功しました（18.369 秒）。横画面の選択表示も確認済みです。
カタログの単体テスト１件と APK／テスト APK のビルドも成功しました。
実機画像８枚、ログ、APK とソースのハッシュは [evidence/theme-selection/](evidence/theme-selection/) に保存しています。

この検証は通常版とは別の `com.kazumaproject.skinfidelity.lite` で行いました。
端末の通常版 APK を更新したという意味ではありません。テスト終了後は元の入力方法へ復元しています。
以前の IME 配置・入力の包括的な検証は [device-regression.md](device-regression.md) の別実行結果です。
今回、同じ全８条件を再実行したとは扱っていません。
