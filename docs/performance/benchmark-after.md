Pixel 6 の同一エディタ、同一 Lite Standard Debug 構成、同一の計測 APK で、10回のウォームアップ後に日英各100回を比較した。候補の観測点は対象ビューの pre-draw。Perfetto を停止した状態で下表を取得した。 [変更前](benchmark-before.md) · [測定方法](benchmark-methodology.md)

|---|---:|---:|---:|---:|
| 日本語「あさ」 | 74.166 → 74.411 ms | 95.122 → 100.712 ms（−5.9%） | 112.294 → 109.681 ms（+2.3%） | 115.382 → 112.518 ms（+2.5%） |

パーセントは変更前を基準にした改善率。200試行のプライマリ候補一覧の内容と順序、確定文字列に差分はなかった。英語は繰り返す同一補完のワークロード。日本語の候補 P95 と英語のエディタ更新 P95 は増加した。今回の変更は英語の補完検索に限定しており、両指標の変動要因は確定していない。

## Perfetto での比較

変更後、変更前の順で収録した別試行。日英各10回のウォームアップ後の12回を集計した。P95 は Perfetto の補間値。キャッシュを有効にした収録全体では、英語の `ke` と `key` の補完検索44回のうち42回が命中した。最初の `key` の辞書探索は33.143 msだった。命中率は同じ入力を繰り返す試行の値。ウォームアップ後の24組でも候補と確定の差分はなかった。

| トレースの区間 | P50 | P95 | 最大 |
|---|---:|---:|---:|
| 英語 UP dispatch | 7.992 → 7.574 ms | 9.449 → 9.505 ms | 9.713 → 9.910 ms |
| 日本語 UP dispatch | 2.990 → 3.450 ms | 3.573 → 4.164 ms | 3.829 → 4.307 ms |
| 英語フレーズ候補 | 27.433 → 14.843 ms | 37.137 → 28.063 ms | 40.421 → 33.264 ms |
| 日本語 DP・N-best | 3.843 → 2.441 ms | 6.820 → 7.263 ms | 7.121 → 8.312 ms |
| 日本語候補の差分計算 | 11.690 → 13.055 ms | 20.577 → 22.314 ms | 23.100 → 23.677 ms |

英語フレーズ候補の P50 は45.9%短縮した。日本語のトレースでは、両構成とも差分計算の P95 が DP・N-best より長かった。日本語の候補表示への影響はレイアウトと差分計算に分けて引き続き確認する。 [描画経路](ui-rendering.md)

| 収録全体のプロセス指標 | 変更前 | 変更後 |
|---|---:|---:|
| FrameTimeline の Late Present 行 | 184 / 995（18.49%） | 179 / 993（18.03%） |
| FrameTimeline の App Deadline Missed 行 | 179 / 995（17.99%） | 175 / 993（17.62%） |
| ART `ThreadFlipSuspendAll` P95 / 最大 | 0.205 / 0.225 ms | 0.280 / 0.460 ms |
| RSS P50 / 最大 | 406.383 / 453.480 MiB | 407.514 / 479.957 MiB |

上表には同一プロセスの計測用エディタと IME の両方が含まれる。Late Present は提示遅延の観測値。候補ごとの実際の提示時刻と欠落フレーム数は未計測。RSS と ART 停止の増加要因は未確定。 [メモリの範囲](memory-analysis.md)

収録の有無による観測差を確認するため、収録なしの最初の12試行と収録ありの12試行を比較した。英語 UP → 候補 pre-draw の P95 は、変更前で 82.564 → 85.685 ms、変更後で 78.364 → 71.127 ms。収録順や端末状態の違いを含むため、収録負荷単独の値は未確定。収録なしの各100回の終了時に記録したバッテリー温度は変更前40.6°C、変更後39.1°Cだった。
